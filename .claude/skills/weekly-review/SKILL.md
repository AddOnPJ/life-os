# 週次振り返り

目的は、**記録から数字と事実を出し、来週の山場と打つ手を決めやすくすること**。感想文や励ましは書かない。
CLAUDE.md のルールに従う。`secure/` の中身は読まない・書かない。

## 1. 対象

- 対象週：実行日を含む週の月曜〜日曜（日本時間）。ファイル名は ISO 週番号 `YYYY-Www.md`。
- 比較：前週の `reviews/weekly/` があれば数字を比べる。なければ比較は省く。

## 2. 集める

- `logs/daily/` の対象週の7ファイル（ないものは「記録なし」）
- Google カレンダー全カレンダー：対象週（実績）と翌週〜2週後（予定）
- `domains/addon/tasks.md` と `domains/addon/events/*.md`
- 前週の振り返りの「来週のフォーカス」（Yuichi が選んだもの）

## 3. 書く内容

```
---
week: 2026-W47
period: 2026-11-16 〜 2026-11-22
logged_days: 5
sleep_avg: 6.4
steps_avg: 7200
exercise_sessions: 3
---

# 2026-W47 振り返り（11/16〜11/22）

## 数字
| | 今週 | 前週 |
|---|---|---|
| 記録した日 | 5/7 | 4/7 |
| 平均睡眠 | 6.4h | 6.9h |
| 平均歩数 | 7,200 | 6,800 |
| 運動 | 3回・95分 | 2回・60分 |
| 食事記録 | 14回 | 10回 |

## 先週決めたフォーカスの結果
- 「◯◯」→ 実績（ログの該当箇所を短く引用）

## やったこと
- AddOn：…
- 仕事・その他：…
（日次ログから。元の言葉を残し、1項目1行）

## AddOn
- 本番：日付・あと何日・準備の進み具合（events ファイルのチェック数 / 全体）
- 期限切れ・今週期限のタスク
- 連絡したこと・返事待ち（ログの「人・連絡」から）

## 来週の山場
- 予定が詰まる日、本番・練習の連続、移動が長い日
- 予定同士の重なり

## 観察（データがあるものだけ）
- 例：練習のあった日は睡眠が平均より短い（3回中3回）
- 根拠の件数を必ず書く。2件以下の傾向は書かない

## 来週のフォーカス候補（提案）
1. …（理由1行）
2. …
3. …
→ 選んだもの：（Yuichi が記入）

## 要確認
- …
```

## 4. 判断のルール

- 数字はログの front matter にある値だけで計算する。欠けている日は分母から外し、そのことを書く。
- 「やったこと」に Yuichi の書いていない成果を足さない。
- フォーカス候補は、来週の山場・期限・先週の未達から出す。一般論（「睡眠を大切に」など）は出さない。
- 既にその週のファイルがあれば「→ 選んだもの」と Yuichi が書いた行を残して、それ以外を更新する。

## 5. 終わり

- `git status` で `secure/` が含まれていないことを確認し、`週次振り返り YYYY-Www` でコミットして push する。
- 最後に、「来週の山場」と「フォーカス候補」を5行以内で報告する（通知に載る文）。
