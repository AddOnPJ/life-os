# クイック記録

目的：Yuichi が外出先から一言送るだけで、記録が life-os に残ること。整形は後で daily-log がやるので、ここでは**速く・正確に・そのまま**残す。

## 手順

1. 送られた内容を、次のどれかに分ける。
   - **ふつう**：予定・やったこと・食事・運動・AddOn・人とのやりとり・メモ
   - **機微**：健康の詳細（症状・通院・薬・検査値・血圧など）、恋愛、お金（収入・支出・残高など）
2. **ふつう** → `inbox/YYYY-MM-DD-HHMM.md`（日本時間）に保存する。
   ```
   ---
   source: phone
   tags: [食事]        # 食事 / 運動 / 予定 / AddOn / 人 / メモ から推測
   ---
   （Yuichi の文をそのまま）
   ```
   - 言い回しを直さない。誤字もそのまま（明らかな変換ミスだけ「要確認」に書く）
   - 時刻が書かれていなければ、受け取った時刻をファイル名に使う。本文に時刻を足さない
3. **食事の写真**があれば、写っているものを推定して本文の下に足す。
   ```
   [写真から推定] 天ぷらそば、ほうれん草のおひたし（推定）
   ```
   量やカロリーは、Yuichi が書いていなければ書かない。
4. **機微** → 平文では保存しない。
   - `python scripts/secure_note.py encrypt --kind love|money|health --text "本文"` で暗号化して `secure-inbox/` に保存する（`pyrage` がなければ `pip install pyrage`）
   - 公開鍵 `keys/age-public.txt` がまだなければ、保存せずに「機微情報の記録は鍵の設定後に使えます（PC で keygen）」と返す
   - 「恋愛記録 苗字」で始まるメッセージ（恋愛コーチの【記録】の転送）は life-os に保存しない。`AddOnPJ/love-coach` を add_repo で追加し、そのリポジトリの CLAUDE.md の手順で追記する。追加できなければ「love-coach リポジトリを開いたセッションで送ってください」と返す
   - 恋愛の相手は**苗字だけ**で書く。下の名前・連絡先・住所・SNS アカウントは書かない（送られてきても省く）
   - 暗号化したら、この会話の返答に本文を繰り返さない
5. `git add inbox secure-inbox` → `記録 YYYY-MM-DD HH:MM` でコミットして push する。`secure/` が含まれていないことを `git status` で確認する。
6. 返答は1〜2行：「記録しました（食事）」のように。写真なら推定した品目を1行で。迷った分類があれば一言だけ聞く。

## 「改善 ◯◯」
仕組みへの要望・不満は inbox ではなく `docs/backlog.md` の「中」の末尾に `- [ ] S番号 内容（Yuichi 日付）` で足してコミット・push。返答は「改善の一覧に足しました（S13）」の1行。

## 「grok」＋貼り付け
Grok Bot の結果を `inbox/YYYY-MM-DD-grok.md` にそのまま保存してコミット・push。AddOn エージェントが翌朝読む。

## まとめて送られたとき

1つのメッセージに複数の出来事があれば、ふつうの部分は1ファイルにまとめ、機微の部分だけ分けて暗号化する。
