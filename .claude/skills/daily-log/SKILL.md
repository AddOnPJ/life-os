# 日次ログ整形

`inbox/` の未処理メモ（スマホなどからの雑な入力）を読み、日次ログに整理して追記する。
CLAUDE.md のルール（機微情報・書き方）に必ず従う。

## 手順

1. `inbox/` 直下の `.md` / `.txt` を古い順に読む（`README.md` と `done/` は対象外）。
   ファイルがなければ「未処理のメモはありません」と報告して終わる。
2. 各メモの日付を決める。
   - ファイル名 `YYYY-MM-DD-HHMM` があればその日付
   - 本文に「昨日」「12日」などがあれば、ファイルの日付を基準に解釈
   - どちらからも決められなければ今日（日本時間）にし、「要確認」に入れる
3. その日付の `logs/daily/YYYY-MM-DD.md` を開く。なければ `templates/daily.md` から作る。
4. メモの各項目を次のセクションに振り分けて追記する。
   - 予定・やったこと / 食事 / 運動・体調 / AddOn / 人・連絡 / メモ
   - 書き方は元のメモの言葉を残す。言い回しを整えない、要約しすぎない
   - 先頭に時刻がわかれば `- 12:30 そば` のように付ける
5. 数値を front matter に入れる。
   - `meals`: `{time, items}`
   - `exercise`: `{type, minutes}`
   - `sleep_hours`
   - メモに書かれていない数値は入れない（推測で埋めない）
6. 健康・恋愛・お金の振り分け
   - 健康（体調・通院・薬・検査値・血圧など）は通常の記録。その日の「運動・体調」に書き、通院・薬・検査結果は `domains/health/log.md` の先頭にも `- YYYY-MM-DD 内容` で足す
   - 恋愛は life-os に書かない（love-coach）。お金の記録は停止中なので、金額・口座のことは書かない（メモにあれば「要確認」で知らせる）
   - 他人の連絡先・住所・本人が人に話していないこと、他人の健康の話は、どこにも書かない（メモにあれば「要確認」で Yuichi に知らせる）
   - 体調の記録はしてよいが、診断や治療の判断は書かない
7. 分類に迷ったものは「要確認」セクションにまとめる。
8. 処理済みのメモを `inbox/done/` に移す（削除はしない）。
9. 最後に報告する：処理した件数、追記した日付ファイル、要確認の項目。

## 注意

- `secure/` の内容を要約してほかのファイルに書かない（いまの secure は Google Health の元データだけ）
- 同じメモを二重に追記しない（既に同じ内容がその日のログにあれば飛ばす）
- コミットするときは `secure/` が含まれていないか `git status` で確認する

入力と出力の例は `examples.md` を参照。
