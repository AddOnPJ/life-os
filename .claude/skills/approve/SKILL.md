# 承認待ちの実行

エージェントは外に出る操作（メール送信・予定登録・掲載の変更など）を自分ではしない。用意したものを `status/approvals.md` に積み、Yuichi の一言で実行する。

## 「承認待ち見せて」
`status/approvals.md` の「待ち」を番号・内容・作成日だけで一覧にする。

## 「A3 OK」
1. `status/approvals.md` で A3 を探す。見つからない・すでに「済み」なら、そう返して何もしない
2. 実行する直前に、**宛先・件名・日時など外に出る中身を2〜3行で示し、「送ります」と一言書いてから**実行する
   - メール送信：Gmail の下書き（approvals.md に書かれた下書き）を送る。下書きが見つからない・中身が変わっていたら送らずに知らせる
   - 予定登録：Google カレンダーに登録する。重なる予定があれば登録せずに知らせる
   - ファイル更新：life-os の該当ファイルを書き換えて commit・push する
   - 改善（improve/ ブランチ）：ブランチの変更点を3行で示し、main に取り込んで push、ブランチを消す。衝突したら取り込まずに知らせる
   - それ以外（掲載サイトの書き換え、投稿、支払いなど）は実行しない。手順を示して Yuichi に任せる
3. A3 を「済み」に移し、`- [x] A3 …（実行: YYYY-MM-DD HH:MM）` にする。commit・push
4. 返答は1〜2行：「A3 送りました（◯◯さん宛て）」

## 「A3 なし」
A3 を「済み」に移し、`（取り下げ: YYYY-MM-DD）` を付けて commit・push。返答は1行。

## 「A1,A3 OK」（まとめて）
番号を並べたものは、並んだ番号だけを上から順に実行する（それぞれ中身を示してから）。番号のない「全部OK」は、一覧を示して番号で返してもらう。

## 決めてほしいこと（D番号）
「D1 外す」「D3 見送り」のように返ってきたら、`domains/addon/agent/decisions.md` の未決から決定済みに日付つきで移し、goal.yaml・tactics.yaml・`domains/addon/recruitment.md` の該当箇所に反映して commit・push。返答は1行。

## 守ること
- 1つの「OK」で実行するのは、指定された番号だけ
- 承認待ちに書かれていない操作は、OK と言われても実行しない
