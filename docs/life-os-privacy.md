life-os プライバシーポリシー

life-os は、運営者個人が自分の健康と生活の記録をまとめるためだけに使うツールです。一般の方への提供はしていません。

1. 取得する情報
運営者本人の Google アカウントから、Google Health API を通じて次の情報を読み取ります（読み取りのみで、書き込み・変更はしません）。
歩数、距離、消費カロリー、活動時間、心拍数、安静時心拍数、心拍変動（HRV）、血中酸素（SpO2）、睡眠、運動、体重

2. 使い道
運営者本人の日々の記録と振り返り、生活の工夫を考えるためだけに使います。広告や販売には使いません。

3. 保存と共有
運営者本人のパソコンと、本人だけが見られる非公開の保存場所に保存します。記録の整理と振り返りに AI（Anthropic の Claude）を使います。それ以外の第三者には提供しません。

4. 取り消しと削除
Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセスを取り消せます。保存した記録は運営者本人が削除できます。
