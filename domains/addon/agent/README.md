# AddOn エージェント（募集・本番・発信）

毎朝 7:13 に動く（`.claude/skills/addon-agent/SKILL.md`）。絶対目標は **2027年3月末までに応募10件**。
5つの立場（募集マーケティング・楽団運営・エージェント設計・SNS・批判役）の意見を突き合わせて 2026-11-18 に設計した。

## 原則
1. 計算と期限はスクリプト（`scripts/addon_agent.py`）、文章は AI、外に出す操作は Yuichi の「OK」
2. 「やった」は観測で閉じる（返信済み＝Gmail の送信済み、掲載の更新＝Yuichi の確認または公開ページ）
3. 計画線より遅れたら、打ち手の在庫（tactics.yaml）から次を承認待ちに出す
4. 推測は「要確認」。取得から48時間を超えた数字は判断に使わない

## ファイル（書き手は1つに決めている）
| ファイル | 中身 | 書き手 |
|---|---|---|
| goal.yaml | 応募の定義、計画線、パート別の欠員 | Yuichi（変更は確認のうえ） |
| applicants.yaml | 応募者ごとの段階と経路（頭文字だけ。連絡先は書かない） | エージェント |
| obligations.yaml | 期限の台帳（id・期限・完了の条件・状態） | エージェント（Yuichi の「済み」で閉じる） |
| experiments.yaml | 実験台帳（判定基準は開始前に固定） | エージェント（採否は Yuichi） |
| tactics.yaml | 打ち手の在庫と優先順位 | エージェント |
| decisions.md | Yuichi に決めてほしいこと | エージェント（決まったら goal / recruitment に反映） |
| status.md | 今日の状態（毎朝作り直す） | スクリプト＋エージェント |
| obs/日付.json | その日の観測値（掲載順位・お気に入りなど） | エージェント |
| runs/日付.md | その日の判断と根拠（数行） | エージェント |
