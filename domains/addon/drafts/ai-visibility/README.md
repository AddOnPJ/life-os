# AI 検索で AddOn が見つかるようにする（S9 の下書き）

ChatGPT・Gemini・Claude・Perplexity などは、サイトの文章に加えて「構造化データ」や「よくある質問」をよく読む。
ここにある3つを addon-pj.com に入れると、「関西 アンサンブル 団員募集」「茨木 楽団 ヴィオラ」などで聞かれたときに拾われやすくなる。
**どれも下書き。サイトに入れるのは Yuichi。** 事実は domains/addon/README.md と recruitment.md に合わせてある。変わったらここも直す。

| ファイル | 入れる場所 | 手間 |
|---|---|---|
| `jsonld.html` | サイトの募集ページ（と、トップページ）の `<head>` か本文の最後。WordPress なら「カスタム HTML」ブロックか、ヘッダーにコードを入れるプラグイン | 5分 |
| `faq.md` | 募集ページの下に「よくある質問」として、見出しと文章のまま貼る | 10分 |
| `llms.txt` | サイトのいちばん上の階層に `https://addon-pj.com/llms.txt` として置く（置けなければ省略してよい） | 5分 |

入れたら、AddOn エージェントが月初の検討会で、実際に AI 検索で出てくるかを確かめる。
